# Erratum / Correction Notice — 47-dataset benchmark & adaptive threshold model

**Date:** 2026-07-08
**Affects:** the Zenodo record "47-Dataset Benchmark Validation Results for PSF v0.4.0" — **both existing versions: v1.0 (`10.5281/zenodo.19323754`) and v1.1 (`10.5281/zenodo.19324360`)** — the calibration model file `src/pathway_subtyping/threshold_model_real47.json`, and the two preprints that cite them (rs-9284565, rs-8913089). A corrected version, **v2.0 (`10.5281/zenodo.21262112`, published 2026-07-08)**, supersedes both; the prior versions remain permanently accessible per Zenodo DOI permanence.
**Issued by:** Rohit Chauhan (author). **Prompted by:** an external reproducibility review that was independently re-verified against the released files.

## Summary
The 47-dataset benchmark and the "adaptive bootstrap threshold model" derived from it (reported at **R² = 0.889**) do not hold. The headline calibration model is **retracted**. The benchmark is **corrected** (invalid rows flagged) and re-released as a new version. The associated manuscript (rs-9284565) has been **withdrawn** from journal review; rs-8913089 is being rebuilt.

## Errors identified and corrected

1. **The R²=0.889 calibration model does not reproduce and is retracted.** Refitting the reported regression (bootstrap ARI ~ silhouette) on the released data gives **R² ≈ 0.11** (slope reversed); on the *valid* rows only (see below) **R² ≈ 0.015**. Silhouette does **not** predict bootstrap-ARI reproducibility in these data; no adaptive-threshold model is supported. The published R²=0.889 (slope +0.914) does not reproduce from the released benchmark and was not verified against it before release.

2. **Empty-input ARI artifact (12 TCGA + 2 GEO rows).** Fourteen rows have degenerate ground truth (`n_true_clusters = 1`), on which `adjusted_rand_score` returns an arithmetically meaningless value rather than measured stability. **Thirteen of the fourteen carry a spurious ARI of 1.0** (all 12 TCGA rows and 1 GEO row); **the fourteenth (GSE136196) returns ARI = 0.0** — the degeneracy is in the ground-truth structure, not detectable from the ARI value alone. These "perfect" 1.0 scores drove the spurious fit. This bug was documented in the repository's own `KNOWN-ISSUES.md` and fixed in one notebook (2026-02-25) but **not** in this benchmark. **Corrected:** these rows are flagged `valid=False` (reason: degenerate ground truth / empty-input ARI artifact). *(Precision correction, 2026-07-09: an earlier version of this notice stated all 14 degenerate rows carried ARI = 1.0; in fact 13 do and the 14th (GSE136196) returns 0.0. The count of degenerate rows — 14 — and every conclusion are unchanged.)*

3. **Impossible ground-truth labels.** GSE92332 lists 1,957 "true clusters" for 533 samples. **Corrected:** flagged invalid.

4. **False independence claim.** The model file and manuscript state the 47 benchmarks exclude the manuscript analysis datasets; in fact **TCGA-COAD** (the manuscript's primary analysis cohort) is present as a benchmark row. **Corrected:** flagged `NOT_independent`; the independence claim is withdrawn.

5. **Count and identifier discrepancies.** The released set (`bootstrap_threshold_calibration_47datasets_zenodo.csv`, 47 rows) contains **41 unique dataset IDs** (not 47; IDs were duplicated across two numbering schemes) and a passing-row sample total of **40,778** (the `ZENODO_47DATASETS_README.md` stated 36,551). **Corrected:** IDs renumbered uniquely (original retained in `dataset_id_original`); counts restated.

## Corrected artifact
`corrected_benchmark_47datasets_v2.csv` — all 47 original rows retained with added `valid` / `invalid_reason` columns (transparent, nothing deleted). **Of 47 rows (37 marked PASS), 22 are valid; 25 are invalid** (10 pre-existing errors + 15 flagged: 14 empty-input artifacts, 1 impossible label, TCGA-COAD non-independent). On the valid rows, silhouette vs bootstrap ARI has R² = 0.015 (no relationship).

## What the corrected benchmark actually shows
A cross-cohort benchmark across public transcriptomic datasets demonstrates that **discrete-subtype reproducibility is strongly dataset-dependent and, on most independent cohorts, low** — reproducibility must be measured per dataset, not assumed. This is a legitimate (negative) methodological result. It does **not** support a silhouette-calibrated adaptive threshold.
